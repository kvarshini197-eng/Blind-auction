Blind Auction 
A beginner level mini project that stimulates a blind auction, which decides the winner.
How it works
*Users enter their name and the bid amount.
*Bids are stored in a python dictionary which is bidding.
*The code decides the highest bidder and the higher bidder wins the auction.
Concepts used
*Python dictionaries.
*User input.
*Loops and conditional statement
*Functions
How to run 
Run blind_auction.py using Python
